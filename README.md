# 🏠 House Price Prediction

A Machine Learning project focused on predicting house prices using Python and Scikit-learn. The project includes data preprocessing, exploratory data analysis, feature engineering, model development, evaluation, and property recommendations.

## 📌 Project Overview

The objective of this project is to build a machine learning model that can predict house prices based on relevant property features.

The project follows an end-to-end machine learning workflow, starting from data preprocessing and exploratory analysis to model training, evaluation, and saving the final trained model.

## 🎯 Objectives

- Understand and preprocess the housing dataset
- Perform Exploratory Data Analysis (EDA)
- Handle missing values and data inconsistencies
- Identify important features affecting house prices
- Build and evaluate machine learning models
- Select an appropriate model for price prediction
- Save the trained model for future predictions
- Generate property recommendations based on relevant features

## 🤖 Machine Learning

The project uses regression-based machine learning techniques to predict house prices.

Model performance is evaluated using appropriate regression metrics such as:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📊 Key Analysis

The analysis focuses on understanding:

- Distribution of house prices
- Relationship between property features and price
- Important factors influencing house prices
- Model performance and prediction accuracy
- Top property recommendations

## 💾 Saved Model

The trained machine learning model is saved as:

The saved model can be loaded later to generate predictions without retraining the model.
